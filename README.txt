Сборка и проверки находятся рядом, в ../.clone-work/:
  build.py             воспроизводимая загрузка и локализация;
  source/              слой совместимости и снимок отзывов;
  cache/               исходные загруженные ресурсы;
  requirements.txt     зависимости для сборки и проверок;
  verify-local-page.mjs статическая проверка.
Обычный просмотр index.html не требует Python или Node.js.
Для повторной сборки используйте Python с requests и beautifulsoup4:
  python build.py
Для обновления исходных ресурсов:
  python build.py --refresh
Для правки текстовых файлов с сохранением уже загруженных бинарных ресурсов:
  python build.py --text-only

build.py собирает исходную копию сайта. Обновлённая версия блога находится
непосредственно в этой папке: blog/index.html, blog/blog.css, blog/blog.js,
assets/ со сжатыми изображениями и совместимый с каталогом offline-ui.js. При повторной сборке
сохраните эти изменения отдельно. Текущая копия также содержит замену
видеоблоков статичными изображениями; исходная сборка может вернуть видео.
